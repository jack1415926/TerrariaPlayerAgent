# 集中实测清单

更新于 2026-11-27。多人实机环境为 tML 2026.9.3.1／Terraria 1.4.4.9，由一名真人通过 Host & Play 进入独立测试世界、控制一个服务器 AI。测试步骤见 [测试入口](testing.md)，历史报告见 [验证记录](validation.md)。

## 当前已验证

| 对象 | 结果与证据 |
| --- | --- |
| 多人角色与显示 | 生成、移动、遇坎跳跃、移动中停止、红队显示、移除重建和关服重进已通过。第二观察端、断流恢复和瞬移观感仍待验 |
| 只读桥 | 本机服务器状态、AI generation、重开世界的 session 变化已核对 |
| 真人短目标 | 真实模型处理中文左右短移；服务器自动验收 A→B→stop 后持续 60 tick 没有恢复旧输入 |
| DeepSeek 固定傀儡 Demo | 真实模型两轮决策。一次 `approach` 从约 280 像素外靠近，向左刺击命中指定傀儡（5 点），移动和攻击输入归零，服务器发送成功反馈 |
| 原生装备与手动战斗 | 起步为铜短剑、铜镐、铜斧各一；铜短剑剑身与原生 `projectile-hit` 已验。铁阔剑通过测试夹具取得，已击杀史莱姆并在同一傀儡上重复 `item-hit` |
| 受伤、死亡、重生 | 自然怪物接触受伤和软核重生已验，代表场景保留背包并清除攻击输入 |
| 原生掉落拾取 | 前后快照确认墓碑进入 AI 背包，数量合计 11；预约保护、满包和部分堆叠也经过本机程序集检查 |
