# 第一批：独立玩家最小演示

状态：0.1.0 已实现并编译打包，用户已确认生成、移动、跳跃正常；其他细项见 validation.md。

## 目标与范围

单个 tModLoader 客户端、单人测试世界。在人类玩家身边生成一个独立 Player 角色，可以通过命令移动、跳跃、停止和移除。人类同时正常操作。

不在本批加入跟随寻路、战斗、存档、自然语言、LLM、Python、HTTP 或 MCP。后续按玩家机制、保存、跟随战斗、Agent 的顺序扩充。

## 实施顺序

1. 确认本机 tModLoader 版本、可用 .NET SDK 和游戏构建入口；阅读匹配版本的玩家更新、输入与绘制调用链。先确定第二个 Player 如何在单人模式得到一次且仅一次的更新，不凭空假设填入玩家数组即可工作。
2. 在仓库内建立最小 C# 模组，只管理一个演示角色。先实现生成、绘制和移除，明确对象、槽位、更新入口与清理职责。
3. 加入有限时长的移动、跳跃和停止。优先使用原生控制字段与物理机制，不用每帧修改坐标假装移动。仅适配已确认必要的全局上下文，退出与异常路径必须恢复。
4. 编译，并在独立测试角色和世界中验收。保存版本、命令、预期与实际、日志和结果。每个阶段均区分构建成功与游戏内通过。

已实现 /tpa 命令和角色控制层；具体操作见 debugging.md，技术选型和代码职责见 technical-design.md。

## 验收条件

- 人类与演示角色是两个独立 Player 对象，位置和生命状态独立；不得用 NPC 外观替代。
- 能生成和移除，重复生成不会产生失控的额外角色。
- 左右移动及跳跃遵循碰撞和物理；输入不污染人类的鼠标、移动或选中物品。
- 停止在下一次控制更新清除持续动作意图；动作超时同样清除。停止不会强制消除空中惯性或赋予免伤。
- 退出世界、卸载模组后无遗留角色或全局输入状态；重新进入可再次演示。

本批仅显示独立生命状态，不承诺装备效果、战斗、死亡复活和保存已经正确；这些是下一批的独立验收项。
