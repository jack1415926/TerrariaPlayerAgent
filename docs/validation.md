# 首批验证记录

日期：2026-10-21。版本：0.1.0。目标环境：Windows、tModLoader 2026.08.3.0、Terraria 1.4.4.9、.NET SDK 8.0.426。

## 已验证

- 从 F 盘仓库调用 build.ps1：编译和 tModLoader 打包成功，0 警告、0 错误。
- 生成 `.local/tModLoader/Mods/TerrariaPlayerAgent.tmod`。
- play.ps1 成功启动独立开发配置，模组加载完成。
- 新建本地测试角色与普通小世界并进入；加载阶段没有发现本项目异常。

## 用户人工验证

用户按第一组命令测试后反馈：“角色出现，移动和跳跃正常”。因此已有人工作为依据的生成、移动、跳跃基本演示。运行日志也记录生成 AI slot=1、human=0。

第二组测试中，用户确认提前停止、连续移除、重新生成及保存退出重进后的清理行为均正常。本批最小演示已有人工作为依据的核心验收结果。

## 剩余未测细项

重复生成、状态计数的具体数值、反方向与墙体碰撞、禁用模组后重载等细项尚未逐项取得记录，不据此推定通过；不阻止本轮已确认的最小演示交付。

自动桌面操作能够点击菜单，但进入世界后无法可靠触发聊天热键，已停止适配这一辅助工具，改由用户手动验证现有命令。没有为工具限制新增调试服务或测试框架。

## 已知功能边界

单人、单角色、无存档、无装备交互、无战斗、无自主跟随、无 Agent。Player 原生代码中本地玩家专属路径尚未适配，后续机制需要分批验证。
