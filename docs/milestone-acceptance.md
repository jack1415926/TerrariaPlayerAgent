## 真实模型闭环

运行既有探索教程：`scripts/run-agent.ps1 -GoalFile agent/prompts/explore.md -MaxTurns 12`。宿主在调用模型前，以AI当前X建立左右25格（400像素）范围；模型没有修改边界的工具权限。

模型共8次请求、7批动作，正常以model_finished结束：

1. 自行选择goto X=33624，从起点33824.57移动到33627.668，误差3.668像素，状态arrived。
2. 选择铜镐，原生移除(2102,295)、(2096,294)、(2095,294)三块草地方块，均有匹配broken事件。一次因受击后距离变化而超范围的挖掘被拒绝，没有假装执行。
3. 受到近敌干扰时切木剑短攻击，未确认命中；没有把它写成击败怪物。
4. 用home从33555.867主动移动265.465像素，到33821.332，距起点3.238像素；本次方向输入131帧，无死亡／重生。所有已记录位置的最大水平偏移268.703像素，未观察到越界标记。

原始报告位于开发机 `.local/test-results/agent-20261022-203223-7d9522.json`（不随公开仓库上传）。**到达瞬间与最终快照须分开**：home确认到达后，模型生成总结期间AI又受击，宿主最终停止快照X=33771.934，离起点约52.64像素、生命81，四类动作计时均归零。到达结果通过，不代表角色能持续守住原地或不受击退。

本轮AI背包仍只有木剑／铜镐，没有泥土入包证据。未改生命、伤害、时间、刷怪或碰撞规则；保留AI，自动重生默认开启。

## 使用与后续

真人可用 `/tpa range 25` 在AI当前X建立活动范围及home，`/tpa range off` 解除；`goto`和`home`的X单位为世界像素，对应actor.x，不是方块列号。目标容差8像素，默认最多10秒。范围与home保留到重新设置／移除／退出世界，普通stop不清除范围。

目标移动只使用原生方向输入和摩擦减速，不改坐标、速度或传送。边界限制主动向外输入，击退、重生和环境仍可能把角色带出范围；outsideBounds如实显示，向范围内移动仍允许。它不是物理围墙。
