# TerrariaPlayerAgent

目标：在 Terraria / tModLoader 中开发一个具有独立生命值、物品、装备、死亡与复活能力的 Agent 队友，最终尝试合作推进至月亮领主。

当前优先单客户端体验，保留独立 AI 客户端为备选。底层角色控制与上层决策解耦。

## 项目文档

- [V0.1 技术需求](docs/requirements-v0.1.md)：整理自用户提供的说明，包含 FR01–FR10、MVP、P0–P4 与待验证问题。
- [P0 可行性调查与原型验收](docs/p0-feasibility.md)：三个参考项目、固定提交的源码依据、风险和最小实验。

- [第一批最小演示](docs/first-demo.md)：用户认可的范围、实施步骤和验收条件。

## 当前状态

- 已完成：项目目录、需求归档、定向源码调查。
- 工程判断：单客户端第二角色路线值得验证。
- 尚未完成：原型代码、构建和游戏内验证。
