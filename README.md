# TerrariaPlayerAgent

在 Terraria / tModLoader 中开发具有独立生命、背包和装备的 AI 队友，长期目标是合作探索并推进游戏。

包版本仍为 **0.1.1**，C# 12 / .NET 8；无第三方伙伴模组依赖。功能状态以本页和验收记录为准，不把包版本号当作全部能力已完成。

公开仓库仅包含源码、脚本和文档，不附带 Terraria／tModLoader、API凭据、构建产物或角色／世界存档。文档中的 `.local/` 路径是开发机上的历史原始报告，不随仓库上传；公开验收结论和边界见下方阶段报告。运行需要自行安装对应游戏和SDK，并按 `.env.example` 配置自己的凭据。

## 当前阶段（2026-10-22）

**单人、游戏保持前台时，基础操作闭环阶段性通过。** 外部 Python Agent 已能自主选目的地、使用铜镐挖掉方块，再主动返回活动起点。最近一轮8次模型请求正常结束，移除3块方块，home到达误差约3.24像素；具体证据和限制见 [阶段性验收报告](docs/milestone-acceptance.md)。

| 能力 | 已实现／已验证 | 当前边界 |
| --- | --- | --- |
| 独立角色 | 生成、控制、停止、移除；原生玩家循环更新 | 单人、一个AI，无持久化 |
| 移动 | 左右、方向跑跳、小坎自动跳、有限恢复跳 | 无完整寻路或悬崖避让；平台下落入口已实现但正向实测待补 |
| 目标与范围 | goto／home、本地刹停、越界目标拒绝、定时输入边界拦截 | 水平目标；容差8像素。范围限制主动输入，不抵消击退或重生 |
| 战斗与重生 | 木剑／铁阔剑原生命中、接触受伤与死亡、软核自动重生已有实测 | 近敌观察已接入，完整自主战斗未通过 |
| 工具与挖掘 | 背包选择、普通挥动镐、原生范围／冷却／方块变化；树下保护已定位并遵守 | 无可靠拾取入包；斧、锤、钻头、放置与合成未交付 |
| Agent任务 | 自然语言Goal、探索教程、顺序动作、实际结果、停止取消旧任务 | 有限轮次原型，尚非持续陪玩；游戏内自然语言入口未交付 |

到达瞬间和最终位置须分开：最近一轮home确认到达后，AI在模型生成总结期间又被击退。它已经主动走回过起点，但没有持续守位能力。角色不会因完成任务而退出世界，宿主只停止输入；自动重生默认开启。

## 开始体验

**换电脑继续开发：先看 [Windows新机接续步骤](docs/new-machine-setup.md)。** 新机通过`-TmlPath`指定自己的游戏安装目录，无需沿用旧机F盘路径；旧存档和密钥不在仓库内。

本机 PowerShell 7：

```powershell
Set-Location 'F:\codex_project\TerrariaPlayerAgent'
.\scripts\build.ps1
.\scripts\play.ps1
```

本机使用 .NET SDK 8.0.426、tML 2026.08.3.0／Terraria 1.4.4.9。其他安装位置可传 `-TmlPath`。本地数据在被Git忽略的 `.local/tModLoader`；测试只用角色 `t` 和普通小世界“放松苔原”，不操作列表里可能出现的正式／云存档。

首次为测试AI准备装备，在游戏中逐条输入：

```text
/tpa spawn
/tpa equip wood
/tpa equip pick
/tpa select 0
```

已有相应装备时不必重复发放。木剑在slot0、铜镐在slot1；这些是开发测试物资，普通初始装备发放及铜短剑仍未接入。退出世界后AI不保存。

配置与凭据按 [Agent说明](docs/agent-setup.md) 放在环境或本地 `.env`，然后运行：

```powershell
.\scripts\run-agent.ps1 -GoalFile agent/prompts/explore.md -MaxTurns 12
```

宿主自动以本轮AI位置设置左右25格范围。模型自行选择路线、目标和工具，完成后直接总结，宿主停止输入并保留角色。**当前必须让游戏保持前台**；切回聊天导致暂停时，任务可能超时，不能当作后台游玩已支持。

在游戏内 `/tpa stop`，或另一PowerShell运行 `.\scripts\run-agent.ps1 -Stop` 可取消旧任务；失焦时仍需游戏处理入口才能确认停止。不要同时启动多个控制器。

## 手动操作要点

| 命令 | 含义 |
| --- | --- |
| `/tpa left 1`、`right 1` | 按模拟秒数移动，默认2秒、最多10秒 |
| `/tpa jump left 1` | 边走边跳；普通jump保留当前水平移动 |
| `/tpa range 25`、`range off` | 以当前AI的X设置范围／home，或解除；模型不能修改 |
| `/tpa goto 33624`、`home` | 到水平世界像素X／返回范围起点，默认最多10秒；坐标示例需按当前状态替换 |
| `/tpa select 1` | 选择已有背包物品 |
| `/tpa mine 2106 295 2` | 对世界方块格坐标用镐，须使用当前观察中的目标，不能盲抄示例 |
| `/tpa attack right 1` | 朝指定方向原地攻击，不自动追敌 |
| `/tpa status`、`stop`、`remove` | 查看状态、停止主动输入、移除对象 |

手动新动作通常替换旧动作，Agent宿主会逐条等待；方向跑跳是组合输入。停止不冻结重力、惯性或已经开始的原生动画。范围保留到重设、移除或退出世界，普通stop不清除它。

## 下一步与开发约定

**下一阶段先完成可指挥的AI队友入口**：按P0中断与安全恢复基础 → P1持续宿主及游戏内目标收发 → P2动态切换与恢复整合逐批开发。公司电脑先做离线逻辑和可用条件下的构建，个人电脑集中验收聊天命令、任务替换及真实失焦行为；之后推进P3近敌反应、P4原生拾取。以上均为计划，当前运行边界不变；交付范围和验收条件统一见 [TODO](TODO.md)。

按小场景交付，先让模型实际尝试再补具体缺口；不逐把武器、逐类地形验收，不重跑未受影响的整套测试。调试窗口输入受阻时复用JSON入口；文档或外部Agent修改不重启游戏。测试辅助功能若改变规则，必须记录，不能将结果当作正常资源／成长规则已通过。
